# Glossário técnico (inglês e português)

Este glossário cresce a cada módulo. Revise 10 termos para desbloquear a habilidade **Tradutor de Documentação**.

## Missão 0: ambiente

| Termo | Pronúncia aproximada | Tradução | O que significa na prática |
|---|---|---|---|
| *install* | instól | instalar | Colocar um programa no computador. |
| *download* | dáun-lôud | baixar | Transferir um arquivo da internet para a máquina. |
| *PATH* | péth | caminho | Lista de pastas onde o sistema procura programas. Se o Python não está no PATH, o terminal não o encontra. |
| *terminal* | têrminal | terminal | Janela onde você digita comandos de texto. |
| *virtual environment* (*venv*) | vârtchual envairônment | ambiente virtual | Uma "caixa" isolada com as bibliotecas de um projeto, para não misturar com outros projetos. |
| *package* | péquedj | pacote | Um conjunto de código pronto que você instala e usa (por exemplo, `pandas`). |
| *pip* | pip | (nome próprio) | O instalador de pacotes do Python. |
| *script* | scrípt | roteiro, programa | Um arquivo `.py` com instruções que o Python executa. |
| *run* | rân | executar, rodar | Mandar o computador seguir as instruções do código. |
| *print* | prínt | imprimir, exibir | Mostrar algo na tela. |
| *input* | ínput | entrada | Dado que o usuário digita para o programa. |
| *repository* (*repo*) | repózitóri | repositório | Pasta de projeto controlada pelo Git. |
| *commit* | comít | registrar, confirmar | Salvar um "ponto da história" do projeto no Git. |
| *push* | púsh | empurrar, enviar | Mandar seus commits para o GitHub. |
| *error* | érror | erro | Algo deu errado. O Python sempre diz o tipo e a linha. |
| *pull* | púl | puxar | Trazer para o seu computador as mudanças que estão no GitHub. |
| *staged* | stêidjd | preparado | Arquivo marcado com `git add` para entrar no próximo commit. |
| *untracked* | ân-tráct | não rastreado | Arquivo novo que o Git ainda não acompanha. |
| *pathspec* | péth-spec | especificação de caminho | O caminho de arquivo que você passou para um comando do Git. |
| *token* | tôuken | ficha, credencial | Chave de acesso que substitui a senha em sistemas e APIs. |

## Missão 1: variáveis, tipos, entrada e saída

| Termo | Pronúncia aproximada | Tradução | O que significa na prática |
|---|---|---|---|
| *variable* | vérriabol | variável | Nome que aponta para um valor guardado na memória. |
| *integer* (`int`) | íntedjer | inteiro | Número sem casas decimais. |
| *float* | flôut | ponto flutuante | Número com casas decimais. No Python, o separador é o ponto. |
| *string* (`str`) | stríng | cadeia de caracteres | Texto, sempre entre aspas. |
| *boolean* (`bool`) | búlian | lógico | Verdadeiro (`True`) ou falso (`False`). |
| *type* | táip | tipo | A categoria de um valor. Confira com `type()`. |
| *prompt* | prômpt | aviso, pergunta | O texto que o `input()` mostra antes de esperar a resposta. |
| *concatenate* | concátenêit | concatenar, juntar | Unir textos com `+`. |
| *literal* | líteral | literal | Um valor escrito diretamente no código, como `300` ou `"Ana"`. |
| *syntax* | síntax | sintaxe | As regras de escrita da linguagem. `SyntaxError` quer dizer que o código está escrito de forma inválida. |
| *defined* | difáind | definido | Que já existe. `is not defined` quer dizer "não existe ainda". |
| *standard output* | stêndard áutput | saída padrão | A tela do terminal, para onde vai o `print()`. |
| *trailing newline* | trêiling niú-láin | quebra de linha final | O Enter que fica no fim de uma linha de texto. |
