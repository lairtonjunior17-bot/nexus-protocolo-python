# Glossário técnico (inglês e português)

Este glossário cresce a cada módulo. Revise 10 termos para desbloquear a habilidade **Tradutor de Documentação**.

## Missão 0: ambiente

| Termo | Pronúncia aproximada | Tradução | O que significa na prática |
|---|---|---|---|
| *install* | instól | instalar | Colocar um programa no computador. |
| *download* | dáun-lôud | baixar | Transferir um arquivo da internet para a máquina. |
| *PATH* | péth | caminho | Lista de pastas onde o sistema procura programas. Se o Python não está no PATH, o terminal não o encontra. |
| *terminal* | têrminal | terminal | Janela onde você digita comandos de texto. |
| *virtual environment* (*venv*) | vârtchual envairônment | ambiente virtual | Uma "caixa" isolada com as bibliotecas de um projeto, para não misturar com outros projetos. |
| *package* | péquedj | pacote | Um conjunto de código pronto que você instala e usa (por exemplo, `pandas`). |
| *pip* | pip | (nome próprio) | O instalador de pacotes do Python. |
| *script* | scrípt | roteiro, programa | Um arquivo `.py` com instruções que o Python executa. |
| *run* | rân | executar, rodar | Mandar o computador seguir as instruções do código. |
| *print* | prínt | imprimir, exibir | Mostrar algo na tela. |
| *input* | ínput | entrada | Dado que o usuário digita para o programa. |
| *repository* (*repo*) | repózitóri | repositório | Pasta de projeto controlada pelo Git. |
| *commit* | comít | registrar, confirmar | Salvar um "ponto da história" do projeto no Git. |
| *push* | púsh | empurrar, enviar | Mandar seus commits para o GitHub. |
| *error* | érror | erro | Algo deu errado. O Python sempre diz o tipo e a linha. |
